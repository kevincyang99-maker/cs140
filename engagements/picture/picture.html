Favority General Conference Talk:

JPEG

JPEG is best for real-world photographs with many colors, details, and smooth color gradients, such as portraits, landscapes, food, and nature photos.

GIF

GIF is best for simple images with a limited number of colors, such as icons, logos, simple graphics, cartoons, and animations.

PNG

PNG is best for logos, icons, screenshots, graphics, and images that require transparency. PNG uses lossless compression, so image information is preserved during compression.

Why should you resize photos using photo editing software instead of resizing it using CSS?

because CSS only changes how large the image appears on the webpage. It does not reduce the actual image dimensions or file size. A large image takes more time and bandwidth to download, even if CSS displays it at a small size. Resizing the actual image before uploading it can reduce the file size and make the webpage load faster.
