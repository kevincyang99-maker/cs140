A pre-set value is actual data already filled in, while a placeholder is only a hint for the user. Text box: Use value for a pre-set value and placeholder for a hint. Textarea: Put the pre-set text between textarea> and /textarea. Use placeholder for a hint. Select box: Use selected on an option to choose the default value. A select box does not have a placeholder attribute, but we can use an empty option as a hint. Checkbox: Use checked to make it selected by default. The value attribute determines what data is submitted. It does not have a placeholder. Radio button: Use checked to select a default option. The value attribute determines what data is submitted. It does not have a placeholder.

HTML5 introduced new input types, including email, url, tel, search, number, range, date, time, datetime-local, month, week, and color. It also introduced datetime, which is now obsolete. Other new form-related elements include datalist, output, progress, and meter. In my current form, I have not used any of the new HTML5 input types. I used text, password, radio, checkbox, and submit, which existed before HTML5. I also used select and textarea, which are older HTML elements.
